# Proiect Laborator Web Design: Aroma Cafe

## Descriere
Acest proiect reprezintă o pagină de prezentare pentru o cafenea clasică. A fost realizat pornind de la un prompt clar în limba română pentru a genera structura HTML5 și CSS3, urmată de verificarea și rafinarea manuală.

## Modificări manuale realizate (Personalizare)
1. **Adăugare efecte vizuale:** Am adăugat manual tranziții pe clasa `.btn` (`transform` și schimbarea culorii de fundal la hover) pentru a face butonul principal mai atractiv.
2. **Optimizare Flexbox:** Am asigurat centrarea perfectă a elementelor din meniu pe dispozitive mobile.
3. **Umbrire:** Am adăugat `box-shadow` pe cardurile de produs pentru a le scoate în evidență pe fundalul deschis.

## Tehnologii folosite
- **HTML5 Semantic** (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- **CSS3**
- **Flexbox** (Pentru navigare și aranjarea produselor)
- **Media Queries** (Pentru aspectul responsive pe ecrane mai mici de 768px).
